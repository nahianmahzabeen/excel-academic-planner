# Excel Academic Planner

An Excel-based academic planning tool designed to organize Chemical Engineering coursework, compare academic stream options, and track elective requirements throughout an undergraduate degree.

## Project Overview

Planning an engineering degree involves managing course sequences, stream-specific requirements, and elective selections. This project consolidates academic planning into a structured Excel workbook, helping users organize course options and monitor their progress toward program requirements.

## Key Features

* **Dual-Stream Planning:** Organizes academic course planning for two Chemical Engineering stream options.
* **Elective Tracking:** Provides a structured way to record elective selections and compare them against applicable program requirements.
* **Automated Requirement Checks:** Uses spreadsheet logic and visual flags to identify elective selections that may need attention.
* **Centralized Course Organization:** Keeps course options and planning information accessible within a single workbook.
* **Visual Planning Interface:** Uses spreadsheet formatting to make course selections and requirement tracking easier to review.

## How to Use

1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Select the relevant academic stream option.
4. Use the planner to organize course choices and record elective selections.
5. Review the requirement indicators to identify selections that may need further checking.

## Project Purpose

This project demonstrates how spreadsheet tools can be used to structure complex information, track requirements, and simplify multi-year planning through organized data and formula-based logic.

*Developed as an independent academic planning project during first-year Chemical Engineering studies at the University of Waterloo.*
